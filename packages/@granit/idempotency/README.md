# @granit/idempotency

Automatic `Idempotency-Key` header injection on mutation requests (`POST`, `PUT`, `PATCH`, `DELETE`) via `@granit/api-client`.

Part of the [Granit](https://granit-fx.dev) framework.

## Installation

Consumed via `link:` protocol — see the [integration documentation](https://granit-fx.dev).

See the [full documentation](https://granit-fx.dev/frontend/infrastructure/idempotency/).
